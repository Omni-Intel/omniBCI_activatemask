OMNIBCI VERSION AND QUICK START
===============================

Current version
---------------
OmniBCI ADS1299 GUI for SRB1-only firmware V19 and communication protocol V1.

BLE is considered ready only after the firmware handshake and ADS1299 register
snapshot succeed. Configuration responses use an independent RESPONSE Notify
characteristic and matching request IDs.

GUI
---
First run:  install_and_run.bat
Later runs: run.bat
Main file:  ads1299_eeg_gui_native.py

V19 firmware
-------------
SRB1:
  firmware/ESP32C3_ADS1299_SRB1_BLE_V19/ESP32C3_ADS1299_SRB1_BLE_V19.ino

Upload/diagnostic port on the current test PC: COM6

SRB2 is not supported in this branch.

Dependencies
------------
Core live-acquisition packages are listed in requirements.txt.
Optional BDF/MNE export packages are listed in requirements_optional_export.txt
and can be installed with install_optional_exports.bat.

The optional packages are not required for live USB/BLE acquisition. A missing
pyEDFlib wheel must not block acquisition, filtering, plotting or BIN recording.
