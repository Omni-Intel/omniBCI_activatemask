OMNIBCI WINDOWS EXE BUILD (V19, STABLE ESP32 EEG SRB1 + BLE)
==========================================================

This builder packages ads1299_eeg_gui_native.py, the same entry as run.bat.
It is NOT the EMG or STM32 product. No firmware is built or modified.

Build computer: Windows x64, uv available on PATH.
Use the project's existing uv installation (as used by install_and_run.bat).
uv installs the Python version and dependencies specified by the project lock.
Network access is needed for uncached packages.

Double-click build_exe.bat, or run from a terminal:
  build_exe.bat                       Full: includes mne and pyedflib
  build_exe.bat --slim                Excludes BDF/FIF export dependencies
  build_exe.bat --non-interactive     Full, without a final pause (CI)

The build uses a separate .buildvenv. The acquisition .venv and uv.lock are
not modified. Slim builds use the same locked build environment but exclude
the export packages from the final distribution.
The PyInstaller subprocess uses only Windows system paths, preventing DLL
collisions with unrelated programs (e.g. other Qt/ICU installations).

Every successful build prints a NEW directory:
  dist\<unique-build-id>\OmniBCI_V19\
Run OmniBCI_V19.exe from that directory. Keep the adjacent _internal folder.
The target computer does not need Python. Copy or ZIP the WHOLE directory,
not just the EXE. Keep it in a writable directory for recordings and logs.

Old build directories are never deleted by this script. They may contain
recordings and logs; archive those before manually cleaning up old releases.

Git policy:
- EXE, MSI and desktop release archives are ignored, including ZIP/7Z/RAR.
- build/, dist/ and .buildvenv/ are local-only.
- Firmware update ZIPs under firmware/ are intentional source exceptions.
- Do not use git add -f for desktop outputs.
- GitHub Actions validates the build only; it does not upload the EXE/ZIP.

If a build fails, keep the FIRST error message and the build\<id> warnings.
If the EXE fails, keep the error dialog and logs\onmibci.log beside the EXE.
An old EXE is not updated by changing the spec; rebuild and use the new path.
OmniBCI_V16.spec is historical and is not used by this builder.
