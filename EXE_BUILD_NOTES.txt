OMNIBCI WINDOWS EXE BUILD AND DISTRIBUTION
==========================================

Recommended format: PyInstaller ONEDIR.

Build machine
-------------
Windows 10/11 x64.
Python 3.12 x64 is recommended; Python 3.11 is also supported by build_exe.bat.

Option A - local one-click build
--------------------------------
1. Install 64-bit Python 3.12 on the build computer.
2. Double-click build_exe.bat.
3. Wait for BUILD SUCCESS.
4. Open dist\OmniBCI_V19\.
5. Send or zip the entire directory.
6. On the target computer, run OmniBCI_V19.exe.

Option B - GitHub Actions
-------------------------
1. Commit the project, including .github/workflows/build-v19-windows-exe.yml.
2. Open the repository Actions page.
3. Run "Build OmniBCI V19 Windows EXE".
4. Download the OmniBCI_V19_Windows artifact.

Distribution rules
------------------
- Send the ENTIRE dist\OmniBCI_V19\ directory.
- Do not copy OmniBCI_V19.exe alone. The adjacent _internal directory contains
  the Python runtime, Qt libraries and scientific packages.
- The target computer does not need Python, pip, pyserial, scipy, PySide6 or
  bleak.
- Recordings are written to OmniBCI_V19\recordings\ beside the executable.
- The live EXE excludes optional mne/pyedflib. Use the source/venv edition when
  BDF/FIF export is required.

Why ONEDIR
----------
- Faster launch.
- Less Windows Defender extraction overhead.
- More reliable Qt/BLE DLL loading.
- Easier diagnosis on different PCs.

Naming note
-----------
The desktop application release is OmniBCI V19. It supports both the original
ESP32-C3 SRB1 firmware and the STM32H563 + E73 + USB dongle compatibility
firmware using device-control protocol V1.
