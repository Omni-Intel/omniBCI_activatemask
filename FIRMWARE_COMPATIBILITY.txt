OMNIBCI V19 FIRMWARE COMPATIBILITY
==================================

This branch supports two fixed-reference ESP32-C3 BLE V19 builds:

  firmware/ESP32C3_ADS1299_SRB1_BLE_V19/ESP32C3_ADS1299_SRB1_BLE_V19.ino
  firmware/ESP32C3_ADS1299_SRB2_DIFF_BLE_V19/ESP32C3_ADS1299_SRB2_DIFF_BLE_V19.ino

Required handshake:
  firmware version V19.1.0 (GUI accepts V19.x)
  device-control protocol V1

Reference selection is intentionally a firmware-build choice, not a GUI control.
The SRB1 build keeps MISC1.SRB1 enabled; the myEMGpcb SRB2 build enables every
active CHnSET.SRB2 switch and keeps MISC1.SRB1 disabled. Both builds support
runtime 250/500/1000 SPS through a transaction-correlated command followed by
CONFIG1 and applied-rate readback. When an ESP32-C3 is opened directly through
its USB CDC port, both builds also accept the GUI's `AA <sample-rate-code>`
serial command and return the shared 12-byte CONFIG1/readback acknowledgement.
For ESP32C3 Dev Module builds, `USB CDC On Boot` must be Enabled only when direct
COM control is needed. BLE operation does not require this build option.

GATT characteristics:
  DATA      reliable EEG blocks
  CONTROL   GUI requests
  STATUS    heartbeat and acquisition/transport diagnostics
  RESPONSE  replies correlated by request ID and complete register snapshots

The hardware has no battery measurement interface. STATUS therefore does not
report battery voltage or percentage.

STATUS V5 is 96 bytes: it preserves the reliable transport prefix and V19
configuration generation, then appends missed-DRDY, late-read, mutex-busy,
bad-status, and maximum-read-time counters. BLE DATA notify congestion is
retried with bounded backoff instead of advancing the reliable sequence.
