OMNIBCI V19 FIRMWARE COMPATIBILITY
==================================

This branch supports only the bundled SRB1 BLE firmware V19:

  firmware/ESP32C3_ADS1299_SRB1_BLE_V19/ESP32C3_ADS1299_SRB1_BLE_V19.ino

Required handshake:
  firmware version V19.0.0
  device-control protocol V1

V19 is SRB1-only. SRB2 firmware, reference switching and A8 probing have been
removed. The GUI reports a BLE connection as ready only after HELLO succeeds and
an ADS1299 register snapshot has been received.

GATT characteristics:
  DATA      reliable EEG blocks
  CONTROL   GUI requests
  STATUS    heartbeat and acquisition/transport diagnostics
  RESPONSE  replies correlated by request ID and complete register snapshots

The hardware has no battery measurement interface. STATUS therefore does not
report battery voltage or percentage.

STATUS V5 is 96 bytes: it preserves the reliable transport prefix and V19
configuration generation, then appends missed-DRDY, late-read, mutex-busy,
bad-status, and maximum-read-time counters. BLE DATA notify congestion is
retried with bounded backoff instead of advancing the reliable sequence.

The test board is currently connected as COM6 for USB upload/diagnostics.
